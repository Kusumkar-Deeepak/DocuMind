### 4.7 Ingestion Engine & Overlap Guarantees

The RAG pipeline standardizes text segmentation into deterministic windows. The standard configuration parameter mandates a chunk_size of 800 characters paired with a sliding chunk_overlap of 100 characters.

When sentences breach the 800-character boundary, splitting falls back to the nearest antecedent terminal punctuation mark (., ?, !) to preserve localized syntactic completeness. Documents are processed using a reciprocal rank smoothing constant k = 60 before feeding downstream rankers.
