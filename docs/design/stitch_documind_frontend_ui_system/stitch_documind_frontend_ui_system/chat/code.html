How does DocuMind merge vector search and keyword BM25 results, and what is the exact chunking configuration?
psychology
DocuMind AI streaming

DocuMind implements hybrid retrieval by concurrently executing pgvector cosine distance search (top 20) and PostgreSQL full-text tsvector search (top 20). The candidate sets are fused using Reciprocal Rank Fusion (RRF):

RRF(d) = ∑m ∈ M ( 1 / (60 + rm(d)) )

where k=60. The fused candidates are then passed through the cross-encoder/ms-marco-MiniLM-L-6-v2 reranker, retaining the top 5 chunks for the final prompt context.

The chunking parameters are configured as follows:

  • Chunk size: 800 characters
  • Chunk overlap: 100 characters
